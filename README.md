# Unidad 5 - Turbo Rush

Juego de carreras arcade para navegador, jugable en **PC y dispositivos móviles**.

## Características
- Interfaz de inicio interactiva (jugar, instrucciones, pausa, reinicio).
- Controles para PC (flechas/WASD, nitro con Shift/Espacio, pausa con P).
- Controles táctiles en pantalla para celular.
- Mecánica arcade: esquiva tráfico, recoge orbes, usa nitro y acumula puntos.
- Estilo visual arcade con escena 3D (Three.js), efectos de velocidad y nitro.

## Cómo jugar
1. Abre `index.html` en tu navegador, o publica el repositorio con GitHub Pages.
2. Presiona **Jugar**.
3. Evita chocar con otros vehículos y consigue la mayor distancia/puntaje.

## Publicar para que todos puedan jugar (GitHub Pages)
1. Ve a **Settings > Pages** del repositorio.
2. En **Build and deployment**, selecciona la rama `main` y carpeta `/ (root)`.
3. Guarda y espera a que GitHub genere la URL pública.

> Nota: Este proyecto es una experiencia web arcade original inspirada en juegos de carreras; no incluye ni replica assets, marcas o contenido propietario de *Blur*.
